# E-commerce Website Products Page List Rendering Project

A project focused on **List Rendering** and **Nested Array Mapping** in React JS using Tailwind CSS and Vite.
---

<img width="1100" height="608" alt="image" src="https://github.com/user-attachments/assets/d1a5bd88-f81d-43f2-94fa-ed77bacbdca4" />

## 🚀 Features

* **Dynamic List Rendering:** Efficiently renders product listings from a local JSON dataset using JavaScript's `.map()` method.
* **Nested Mapping:** Maps inner array items (product details, key specs) seamlessly inside main component lists.
* **Tailwind CSS Styling:** Uses utility classes for clean layouts, flexbox structures, badge formatting, and custom spacing.
* **Component Keys Management:** Assigns unique `key` props for list optimization and reconciliation.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React JS (Vite)
* **Styling:** Tailwind CSS
* **Data Source:** JSON (`data.json`)
