# VibeSpace 🚀

A modern, responsive community dashboard interface built with **React**, **Material UI (MUI)**, and **Vite**.

---

## 🌟 Features

1. **Responsive 3-Column Layout**: Implemented using MUI `Stack` for a seamless desktop and mobile experience.
2. **Dynamic UI Components**:
    - **Navbar**: Professional navigation with search, badges, and profile menu.
    - **Sidebar**: Interactive navigation list with collapsible menu items.
    - **Feed**: Social-style feed cards for media and content.
    - **Rightbar**: Sidebar for friend status updates and recent conversations.
3. **Material UI Integration**: Leverages MUI's robust component ecosystem (AppBar, Card, List, Avatar, etc.).

---

## 📁 Project Structure

```text
src/
├── components/
│   ├── NavBar.jsx       # Header with search & notifications
│   ├── SideBar.jsx      # Navigation menu with collapsible items
│   ├── Feed.jsx         # Post feed component
│   └── RightBar.jsx     # Friends and conversation updates
├── App.jsx              # Main layout orchestration
└── main.jsx             # React entry point
```

## 🚀 How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
